# Watch 1.0.5 component identities

This integration preserves the completed Waterfall, battery power-screen and NOVA Frequency Generator source commits. The Watch tap preference changes its shared linked sleep client, so all affected utility apps receive distinct source versions before publication. New-feature versions remain Battery 1.1.0 and Frequency Generator 0.1.4. Other current clients advance to Calculator/Stopwatch 0.1.6, Alarms 0.2.2, Countdown 0.1.5, Spectrum 0.4.4, LoRa Messages 0.1.2, BLE Scanner 0.1.1 and Waterfall 0.1.3. Data schemas, private namespaces and existing release records are unchanged.

Alarm service 0.4.2 adds an optional successful-Light-resume boundary so retained sleep does not compare independent suspended clocks as an awake time edit. Its original table prefix and durable records are unchanged. The legacy ordinary service source advances to 0.1.1 for the same append-only suffix. The Watch caller must validate the extension and report only confirmed successful Light returns.

Spectrum 0.4.5 is reserved for the subsequent neural/room-recognition increment.
It preserves the delivered 0.4.4 source and frozen Watch 1.0.6 dependency pin;
this Utilities branch change is not a Watch payload replacement.
