# Shared Watch quick-controls integration versions

This version increment identifies applications rebuilt with the shared
System-Apps quick-controls adapter by Watch's explicit current-app profile.
Application models, private settings, scheduling and audio-level semantics are
unchanged. The Watch current-cohort builder selects the shared source, links
its controller/renderer/session and records exact dependency commits.

The standalone legacy builders retain their existing profiles and source pins.
No Watch 1.0.1 tag, release descriptor or immutable artifact is changed. The
integration candidate requires review and has not been merged or released.
