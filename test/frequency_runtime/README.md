# Frequency real Runtime witness

Uses the production shared Frequency application, published Runtime13eca dynamic
loader/provider graph and actual generic scene host/presentation profiles. Native
navigation moves focus and confirms real semantic controls; the app observer
only reads model/document/focus and cannot inject scene events or change state.

Three native geometries each run demand, retained-provider and no-UI cases.
Each UI case starts440Hz/100%, starts paced256-frame PCM, changes frequency to540Hz
and level to99%, stops, exits, unloads and repeats from defaults. No-UI cases
assert zero physical endpoint I/O. Every profile uses identical host app bytes.

Display, navigation and audio hardware are deterministic endpoints. The clock
and audio writes advance a deterministic shared monotonic timeline. This fixture
does not execute physical audio, selected firmware, the real alarm scheduler,
Context/BLE services or resident Home. Their bounded controller/public-contract
proof is separate; this witness must not be described as full native firmware.

Per-TU compiler closures include runtime/test/SDK and owning public key-contract
inputs. Final hash checks reject mutation during qualification. Failed earlier
runs and corrected generic header-focus regression remain separate receipts.
